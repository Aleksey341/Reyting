# Инструкция по импорту Excel файла с оценкой эффективности

## Проблема

При импорте Excel файла "Оценка поддержки руководителя для теста.xlsx" данные не загружаются в дашборд, и все баллы остаются равны 0.

## Решение

Excel файл имеет **многолистную структуру** (19 листов), где каждый лист соответствует одному критерию оценки. Код уже поддерживает этот формат, но нужно убедиться, что названия листов совпадают с маппингом.

## Структура каждого листа

Каждый лист имеет **стандартную структуру**:

### Первая строка (заголовки)
- **A1:** Муниципалитет
- **B1:** Глава МО
- **C1-E1:** Данные для оценки (варьируются в зависимости от критерия)

### Строки 2-21 (данные)
- **A2-A21:** Названия муниципальных образований
- **B2-B21:** Фамилии глав МО
- **C2-E21:** Значения для расчета (да/нет, числовые, проценты и т.д.)

## Как работает импорт

1. **Обнаружение формата:** Код проверяет, есть ли более 10 листов с названиями критериев → определяет как multi-sheet формат

2. **Маппинг листов:** Для каждого листа находит соответствующий код критерия (pub_1, closed_2, pen_3 и т.д.)

3. **Парсинг данных:** Читает каждый лист с помощью pandas:
   - Берет первую строку как заголовки
   - Пропускает столбцы "Муниципалитет" и "Глава МО"
   - Остальные столбцы - это данные для оценки

4. **Расчет баллов:** Использует `IndicatorScorer.score_indicator()` для каждого муниципалитета и критерия:
   - Да/нет вопросы → считаются "Да" ответы (0-3)
   - Проценты → конвертируются в баллы по методике (0-5)
   - Категории → маппируются в баллы (0-3)
   - Числовые значения → делятся и масштабируются

5. **Сохранение в БД:** Результаты сохраняются в таблицу `fact_indicator` с:
   - `mo_id` - муниципалитет
   - `period_id` - период (месяц)
   - `ind_id` - индикатор
   - `score` - рассчитанный балл

6. **Агрегирование:** Автоматически рассчитываются итоговые баллы:
   - `score_public` = сумма pub_1...pub_9
   - `score_closed` = сумма closed_1...closed_8
   - `score_penalties` = сумма pen_1...pen_3
   - `score_total` = score_public + score_closed + score_penalties

## Как импортировать файл

### Вариант 1: Через API (если API запущен)

```bash
# Через curl
curl -X POST "http://localhost:8000/api/data-import/import-official-methodology" \
  -F "file=@./Оценка поддержки руководителя для теста.xlsx" \
  -F "period_month=2024-01"
```

### Вариант 2: Через Python скрипт

```python
import requests

file_path = r"C:\Users\cobra\Desktop\Дашборд Липецкой области\...\Оценка поддержки руководителя для теста.xlsx"

with open(file_path, 'rb') as f:
    files = {'file': f}
    data = {'period_month': '2024-01'}
    response = requests.post(
        'http://localhost:8000/api/data-import/import-official-methodology',
        files=files,
        data=data
    )
    print(response.json())
```

## Возможные проблемы

### Проблема: "Лист 'X' -> NO MATCH"
**Причина:** Название листа не совпадает с маппингом
**Решение:** Проверьте точное название листа в Excel и сравните с `criterion_name_to_code` в `data_import_routes.py`

### Проблема: "Все баллы = 0"
**Причины:**
1. Данные не были найдены (неправильное имя листа)
2. Данные не были распознаны как числовые (формат столбца)
3. `IndicatorScorer` вернул 0 (пустые столбцы данных)

**Решение:**
1. Проверьте логи импорта
2. Убедитесь, что в каждом листе есть данные в строках 2-21
3. Проверьте названия столбцов - не должны содержать "Муниципалитет" или "Глава МО"

### Проблема: "Municipality 'X' not found"
**Причина:** Муниципалитет из Excel не найден в БД
**Решение:**
1. Проверьте правописание названий МО в Excel
2. Убедитесь, что МО загружены в таблицу `dim_mo`
